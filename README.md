## Deployment Instructions

### GitHub Pages
1. Upload the entire folder to GitHub repository
2. Go to Repository Settings → Pages
3. Select main/master branch as source
4. Website will be available at: https://your-username.github.io/repository-name/

### Cloudflare Pages
1. Upload to GitHub repository first
2. Log in to Cloudflare dashboard
3. Navigate to Pages → Create a project
4. Connect to GitHub repository
5. Deploy settings will automatically detect the project
6. Get a free HTTPS domain name
